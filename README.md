# 📐 Numerical Analysis Projects

Collection of projects developed for the study and application of numerical analysis methods. The repository includes different tools for solving mathematical problems through numerical methods, combining web development with mathematical algorithms.

## ✨ Projects

### 🧮 Linear Equation Systems Calculator

A calculator for solving **nxn systems of linear equations**. The application allows users to enter the coefficients of a system and obtain its solution using different numerical methods.

**Methods implemented:**

* Montante Method
* Gauss-Jordan Method

The calculator was developed using JavaScript, allowing the mathematical operations to be performed directly through the web application.

---

### 📈 Newton-Raphson Method

A web application that implements the **Newton-Raphson numerical method** for finding approximate roots of equations.

The project allows users to provide the necessary values and obtain an approximation of the root through an iterative process.

---

### 📊 Interpolation

A web application focused on solving interpolation problems using numerical analysis techniques.

The project allows data points to be processed to obtain an approximation between known values.

## 🚀 Getting Started

### Prerequisites

For the JavaScript project:

* A web browser

For the Flask projects:

* Python 3
* Flask

### Running the Flask Projects

1. Clone the repository:

```bash
git clone https://github.com/An-Isa93/AnalisisNumericoh.git
```

2. Navigate to the project you want to run:

```bash
cd project-folder
```

3. Install the required dependencies:

```bash
pip install flask
```

4. Run the application:

```bash
python app.py
```

5. Open the URL shown in the terminal in your web browser.
